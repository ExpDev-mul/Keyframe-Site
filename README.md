# Keyframe Language Site

The official website for the **Keyframe** programming language, featuring clean documentation, interactive examples, and a modern developer-friendly interface.

## Features

- Comprehensive documentation for the Keyframe language
- Built with Next.js and Tailwind CSS
- Responsive, minimal UI optimized for readability
- Easy navigation and syntax-highlighted examples

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Keyframe-Site.git
   cd Keyframe-Site
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This site is deployed via GitHub Pages or can be hosted on any static-compatible platform using Next.js static export:

```bash
npm run build
npm run export
```
